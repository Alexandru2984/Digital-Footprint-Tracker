# ops/ — live infrastructure snapshots

Version-controlled copies of the production infra config for `swift.micutu.com`.
These are **snapshots** of what runs on the VPS — the authoritative live files
live at `/etc/nginx/...` and `/etc/systemd/system/...`. Keep them in sync when
you change the live config (or regenerate with the scripts under `scripts/`).

## nginx/
- `swift.micutu.com` — the vhost. Highlights:
  - Security headers (HSTS preload, CSP hash-pinned, X-Frame DENY, …).
  - `include snippets/cloudflare-realip.conf` — anti-spoofing trust list.
  - Per-location rate-limit zones; `CF-Connecting-IP` forwarded as the validated
    `$remote_addr` (not the raw, spoofable client header).
  - (OCSP stapling was tried but removed: Let's Encrypt certificates no longer
    carry an OCSP responder URL, so `ssl_stapling` is a no-op that only warns.)
- `snippets/cloudflare-realip.conf` — generated by
  `scripts/update-cloudflare-ips.sh`. Makes nginx honour `CF-Connecting-IP` only
  when the TCP peer is a Cloudflare edge, so a direct-to-origin request cannot
  forge its source IP.

## systemd/
- `swift-vapor.service` — the unit (runs the release binary as `micu`).
- `swift-vapor.service.d/10-hardening.conf` — sandbox (ProtectSystem=strict,
  ProtectHome=read-only, NoNewPrivileges, restricted syscalls/address families…).
- `swift-vapor.service.d/20-bind-loopback.conf` — binds the app to `127.0.0.1`
  only; nginx on localhost is the sole ingress.

## Regeneration
- Cloudflare ranges: `scripts/update-cloudflare-ips.sh` (validate + reload + rollback).
- CSP script-src hashes: `scripts/update-csp-hashes.sh` (run by `scripts/deploy.sh`).
