What an email address reveals

An address is the strongest starting point in open-source intelligence, because platforms verify it. The scanner asks the sources that can tie an address to an account and keeps the reason each one gives:

  • GitHub links commits to an account only through a verified email, so a commit authored with the address names its owner. A public profile email is checked too.
  • Gravatar returns the profile behind the address and the social accounts Gravatar verified for it.
  • OpenPGP keys: keys.openpgp.org lists only addresses whose owner confirmed them, so the other addresses on the same key belong to the same person.
  • Account registrations: Holehe asks sites’ password-recovery flows whether they know the address, revealing accounts on services such as Spotify, Office 365 or Eventbrite.
  • Data breaches from XposedOrNot (free) and, optionally, Have I Been Pwned: which breaches, when, and what was exposed.
  • The address’s own domain: for a mailbox on a domain of its own (not Gmail or Outlook), the domain is scanned too — its registrant, website and the services it uses.

From one address to a whole footprint

Every confirmed account is followed further. The local part of the address is searched as a username, a GitHub account leads to its Keybase proofs, its SSH keys and the website it lists, and a domain proven on Keybase is scanned in turn. Each step is a link in a chain, and the chain is what decides how sure the tool is that an account belongs to the person.

Links a platform verified count for 98%, links the person published for 90%, a shared username for 40%. An account found only because it shares a name never takes over the profile. How the scoring works.

Questions

Can I find who owns an email address?

Often. When a platform has verified the address — a GitHub commit, a Gravatar profile, an OpenPGP key — the account and the name on it are attributed with high confidence. Addresses that were never used publicly reveal little.

Does the lookup alert the owner?

No. Every source is queried passively; nothing is sent to the address. Account-recovery checks never complete a reset.

Is the email lookup free?

Yes. Account registration checks and the 480-site username sweep need a free, verified account; everything else runs anonymously.
