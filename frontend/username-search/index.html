Hundreds of sites, without the noise

Most username checkers ask each site for a profile URL and report every page that loads. Many sites answer “200 OK” for any name at all — a login wall, a catch-all page — so the result is a long list of accounts that do not exist.

This scanner asks every site that reports a hit about a random name nobody owns as well. A site that “finds” that one too cannot tell real accounts from missing ones, and its hit is dropped. On a typical scan this removes more than half of the raw hits.

Dedicated profile lookups

For the platforms that matter most, a profile API is read instead of a status code: GitHub (profile, organisations, social accounts and the addresses GitHub verified on the account’s GPG keys), GitLab, Codeberg, Keybase, Mastodon, Bluesky, Telegram, Hacker News, Steam, DEV Community, Lobsters, Duolingo, Lichess, speedrun.com, npm, PyPI, crates.io and Docker Hub.

Is it the same person?

Two accounts with the same name may belong to strangers. The scanner looks for evidence that ties them:

  • The same SSH key on GitHub, GitLab and Codeberg accounts.
  • The same profile picture on two platforms, compared by a perceptual hash; generated avatars and plain placeholders never count.
  • What a profile says about its owner: the contact address and other accounts written in a bio or a GitHub profile README.
  • Keybase proofs: signed statements tying a Keybase identity to Twitter, Reddit, Hacker News, GitHub and domains.
  • Links the person published: the Twitter on a GitHub profile, the accounts on a DEV or Lobsters profile, the verified rel=me links on Mastodon.

Accounts tied by such evidence are reported as confirmed; the rest are kept apart as found by name alone. How attribution works.

Questions

How many sites are checked?

Around 480 through the Sherlock project’s site data, plus about twenty platforms read through their own profile APIs.

Why are some accounts marked unconfirmed?

A matching username proves only that the name is taken. Unless something ties the account to the others — a shared SSH key, a signed proof, a published link, the same profile picture — it stays unconfirmed.

Do I need an account?

The 480-site sweep needs a free, verified account. The dedicated profile lookups run anonymously.
