IP address lookup

What an IP address exposes, who operates it and whether it has a reputation.

Run a free scanHow it works

What is checked

  • Open ports and known vulnerabilities from Shodan’s free InternetDB: ports, CVEs, hostnames and tags. A host answering only on web ports is reported as a website, not as an exposure.
  • Network ownership: the routed prefix, origin AS and operator from RIPEstat, and the allocation from the regional registry’s RDAP.
  • Reputation: whether GreyNoise has seen the address scanning the internet, and optionally Shodan, AbuseIPDB and VirusTotal.
  • Tor: whether the address is a current Tor exit relay, checked against the Tor Project’s list.
  • Domains it serves: the host name the address answers to (reverse DNS) and the other domains hosted on it. A meaningful host name is followed as a lead of its own; provider-generated names are not.

Clean verdicts are reported as clean and add nothing to the risk score; only real findings do.

Questions

Can I find who is behind an IP address?

You can find the network operator and the organisation the block is allocated to. Identifying an individual requires the provider’s records, which are not public.

Are internal addresses supported?

No. Private, loopback and cloud-metadata addresses are refused, both as input and when discovered during a scan.
