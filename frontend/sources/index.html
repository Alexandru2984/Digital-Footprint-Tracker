OSINT sources

Every scan queries the sources that fit its input. Most are free and need no key; a few take an optional API key.

Email

SourceWhat it reveals
GravatarProfile, display name and the accounts Gravatar verified for the address
GitHub commits and profilesThe GitHub account and author name behind an address, from its commits or public profile email
keys.openpgp.orgOther addresses verified on the same OpenPGP key
Ubuntu keyserverNames on public PGP keys that mention the address (unverified, weighed accordingly)
HoleheSites whose account recovery recognises the address (verified accounts)

LeakCheckA second breach index, merged with the first: one breach is counted once, whatever each calls it (free)

Email intelligenceDeliverability, mailbox provider and disposable-address detection
Mail securitySPF, DMARC, DKIM, MTA-STS, DNSSEC and CAA of the address’s own domain

Mastodon, BlueskyProfiles, verified rel=me links and DNS-verified domain handles

Domain

SourceWhat it reveals

Passive DNSHistorical resolutions and further subdomains
HomepageThe owner’s accounts marked rel=me, profile links, contact address, phone and author
Tracking IDsThe Google Analytics, Tag Manager, AdSense and Meta Pixel IDs the site embeds, and the other sites that embed the same ones (HackerTarget)
Web postureTLS, HTTP security headers and server fingerprint
Exposed filesContent-verified .env, .git, database dumps and backups left public
Wayback MachineFirst and last archive snapshot, and how many
TyposquatsLookalike domains that resolve
Keybase, BlueskyAccounts that proved control of the domain
