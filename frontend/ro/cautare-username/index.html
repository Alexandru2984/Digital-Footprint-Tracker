Sute de site-uri, fără zgomot

Majoritatea instrumentelor de căutare după username cer fiecărui site pagina de profil și raportează orice pagină care se încarcă. Multe site-uri răspund „200 OK” pentru orice nume — o pagină de login, una generică — așa că rezultatul e o listă lungă de conturi care nu există.

Scanerul întreabă fiecare site care raportează un cont și despre un nume aleator, pe care nu-l are nimeni. Un site care „găsește” și numele acela nu poate deosebi conturile reale de cele inexistente, iar rezultatul lui e eliminat. La o scanare obișnuită, asta elimină peste jumătate din rezultatele brute.

Profiluri citite direct

Pentru platformele importante se citește profilul prin API, nu doar un cod HTTP: GitHub (profil, organizații, conturi sociale și adresele verificate pe cheile GPG), GitLab, Codeberg, Keybase, Mastodon, Bluesky, Telegram, Hacker News, Steam, DEV Community, Lobsters, Duolingo, Lichess, speedrun.com, Linktree, Hugging Face, Gravatar, Codeforces, LeetCode, Wattpad, npm, PyPI, crates.io și Docker Hub.

E aceeași persoană?

Două conturi cu același nume pot fi ale unor străini. Scanerul caută dovezi care le leagă:

  • Aceeași cheie SSH pe conturile de GitHub, GitLab și Codeberg.
  • Aceeași poză de profil pe două platforme, comparată printr-un hash perceptual; avatarurile generate și imaginile uniforme nu contează.
  • Ce spune profilul despre proprietar: adresa de contact și celelalte conturi scrise în bio sau în README-ul de profil GitHub.
  • Dovezi Keybase: declarații semnate care leagă o identitate Keybase de Twitter, Reddit, Hacker News, GitHub și domenii.
  • Link-uri publicate de persoană: Twitter-ul de pe profilul GitHub, conturile de pe un profil DEV sau Lobsters, link-urile verificate rel=me de pe Mastodon.

Conturile legate astfel apar confirmate; restul rămân separat, ca găsite doar după nume. Cum funcționează atribuirea.

Întrebări

Câte site-uri sunt verificate?

Aproximativ 480, din datele proiectului Sherlock, plus vreo douăzeci de platforme citite prin API-ul lor de profil.

De ce unele conturi apar neconfirmate?

Un username identic dovedește doar că numele e luat. Dacă nimic nu leagă contul de celelalte — o cheie SSH comună, o dovadă semnată, un link publicat, aceeași poză de profil — rămâne neconfirmat.

Am nevoie de cont?

Căutarea pe 480 de site-uri cere un cont gratuit, verificat. Profilurile principalelor platforme se verifică anonim.
